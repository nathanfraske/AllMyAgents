# AllMyAgents v0.1.23-alpha.27

Released 2026-08-09.

## Purpose

This is the publishable successor to the gate-failed `v0.1.23-alpha.26` tag. It carries the complete cumulative
feature and fix set documented in [the alpha.26 notes](v0.1.23-alpha.26.md), including project-aware remote
testbeds, deployable lightweight nodes, durable manager teams, remembered bounded approvals, direct role/tool
guidance, large-journal history reliability, dashboard usage polish, and action-required manager/Overseer wakes.

Alpha.26 was never published: its exact-tag Windows durability run found an intermittent installed-shortcut launch
with no application process, no desktop log, and therefore no healthy hub. The release gate correctly refused to
build or publish assets. This cut retains that failed tag as immutable evidence and fixes the release path instead
of moving it.

## Windows installed-startup gate

- The clean-install gate still launches the real Start Menu shortcut and requires the packaged hub to answer its
  authenticated health endpoint.
- If Windows ShellExecute accepts the shortcut but creates neither an AllMyAgents process nor a desktop log, the
  gate retries that same shortcut once. It does not retry when the application began startup, so dependency,
  journal, hub, and renderer failures remain fatal.
- Evidence collection now runs even after a failed health check. The artifact records the shortcut target,
  arguments and working directory, installed process state, port 7777 owner, and the newest native desktop log.

## Journal-maintenance result durability

- The out-of-process backup worker now holds its IPC channel open until the hub acknowledges the terminal result.
  This removes a Windows event-order race where the snapshot and recovery generation were fully verified and
  published, but child exit reached the parent before the final result frame and maintenance was marked failed.
- IPC disconnect releases the worker immediately if its parent disappears, with a 30-second last-resort guard
  only for a live but permanently wedged parent; partial-generation and crash-atomic publication rules are unchanged.
- Focused backup and lifecycle verification passes all 26 tests, including the real compiled ESM worker path.
