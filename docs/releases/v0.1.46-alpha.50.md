# AllMyAgents v0.1.46-alpha.50

## Hub responsiveness and team coordination

- Bounded operational session reads now use the existing session index instead of
  scanning the lifetime journal for every old or idle chat. This addresses a verified
  source of long hub pauses during status, team queries and turn admission. In a
  read-only production-journal comparison, the same 100 rows took about 7 seconds
  through the old scan and 2.7 milliseconds through the index. This is a query
  measurement, not a claim that every latency or network problem is solved.
- Task boards replay complete task-relevant state rather than stopping after the first
  10,000 raw events. Existing saved assignments become visible again without recreating
  them. Recovery aliases already created by agents are not automatically deleted.
- Usage-limit errors no longer wake another agent on the same known exhausted account.
  Fresh reset/healthy usage evidence re-enables ordinary delivery; operator-visible
  errors and audit records remain. Provider policy refusals are not treated as quotas.
- Worktree collision checks distinguish shared accepted ancestry from independent
  branch work. Protected main can stay behind without thousands of false pair/path
  warnings. Genuine overlaps still warn; new warnings are batched with bounded samples
  and full current risks stay visible in project activity.

## Rich chat rendering

- Inline and display math render from dollar or LaTeX delimiters, with fenced math and
  LaTeX equations supported too. Code/currency stays literal; invalid or oversized
  expressions fall back to source.
- Mermaid fences render diagrams through an isolated, network-restricted renderer.
  Source remains available; incomplete/invalid diagrams show a recoverable fallback.
- Clicking an image opens an application-window gallery. Left/Right arrows cycle
  through loaded images from the same chat. Escape closes only the gallery, without
  also invoking underlying chat shortcuts.

## Updating and remaining boundaries

The numeric app version is **0.1.46**, so 0.1.45 clients can detect this release through
Settings → Check for updates. Installing the update relaunches the app; no OS reboot
is needed. Publishing does not restart your current app, devices or mesh services.

This release does not repair a remote MyOwnMesh service's denied control-pipe ACL or
add the still-blocked native K3 bootstrap contract. Large `peek_agent` changes/all-view
diff output remains a separate known issue; use narrower views for large vendor trees.
The journal repairs preserve durable history, do not blanket-truncate payloads, and
use complete raw replay while an index is still backfilling rather than dropping state.
