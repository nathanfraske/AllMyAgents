# AllMyAgents v0.1.51-alpha.55

Includes GPT-6.1 Sol and the accumulated transfer, updater, operator-control and restart patches prepared for v0.1.50-alpha.54. That candidate stayed unpublished after Intel Mac DMG packaging failed; its tag and draft are preserved.

## Intel Mac packaging repair

The release action was forcing Finder's cosmetic icon-layout AppleScript on a headless fleet Mac. Compilation and signing succeeded, but that layout step failed with error -10810. Local Mac release builds now use Tauri's supported headless DMG mode. DMG creation, code signing, signed updater artifacts, installed-app checks and complete-platform publication remain required. Hosted Apple Silicon packaging is unchanged.

## Included changes

- Account-discovered `gpt-6.1-sol`, with low through max reasoning choices and bundled Codex 0.159.2. Existing model selections and Daybreak preferences are preserved. Empty or hidden-only account catalogs no longer turn into fallback model lists. Provider entitlement is still required.
- Checksum-verified whole-file uploads and downloads use bounded 8 KiB application chunks. Negative remote response acknowledgements are surfaced without replaying the underlying operation. Legacy testbed updates use bounded, checksummed staging with recovery information.
- Persisted tool-help holds appear in the chat's review controls. Decisions apply to the exact incident, and stale responses cannot restore a resolved hold. Existing operator settings, including disabled automatic tool escalation, remain unchanged.
- Hub-only restarts preserve the supervisor's agent-tool credential so surviving workers can reconnect. Full application restarts rotate it. Authentication and operator-only controls remain enforced.
- Already-displayed desktop notices are remembered by bounded opaque IDs, preventing repeat alerts after reload when acknowledgement failed. The notification inbox remains available.
- Includes the task-first/stop lifecycle, existing-agent migration, usage warnings and protections for direct operator work. No permissions are broadened.

The [previous candidate notes](https://github.com/nathanfraske/AllMyAgents/blob/v0.1.50-alpha.54/docs/releases/v0.1.50-alpha.54.md) contain the detailed patch history. All platforms stage into one exact-source draft; publication requires complete installers, signed updater assets and Linux packages.

## Updating

Desktop updater version is **0.1.51**. Fully quit and reopen the application once after the first upgrade from an older supervisor. No OS reboot or Mesh upgrade is required by these patches. Remote nodes still require their own authorized update.

Linux amd64/arm64 packages are remote-node packages, not a Linux desktop application. Windows installers are not Authenticode-signed; macOS builds are ad-hoc signed and unnotarized. The existing macOS installer script and documented quarantine workaround remain applicable. This remains an alpha release.
