# AllMyAgents v0.1.33-alpha.37

Released 2026-08-21.

## Purpose

This release fixes the slow, laggy main conversation area on long-running chats and makes provider accounts a
single fleet-wide catalog. Credentials remain local to each device; the catalog reports where the same identity is
logged in and makes adding that identity to the current device direct and verifiable.

## Responsive long conversations

- Invisible high-rate Codex command-output and reasoning-summary fragments still advance the replay cursor, but no
  longer wake every reactive session and app-wide subscriber. Their completed durable item remains authoritative.
- The normal transcript view reverse-scans only the newest 120 visible main-thread items before grouping them.
  Previously it filtered and grouped the complete retained transcript on every streamed update and discarded the
  old prefix only afterward.
- Once the operator explicitly loads older history it remains contiguous and lossless. Chromium
  `content-visibility` containment skips layout and paint for offscreen rows while preserving scroll geometry.
- The active-turn timer now updates at its displayed one-second precision instead of invalidating the busiest view
  four times per second.
- Reverse lookups replace repeated oldest-first scans for live tool, sub-agent, compaction, and optimistic-message
  updates, so current work remains effectively constant-time as retained history grows.

## Shared fleet account catalog

- Each managed Claude or Codex profile projects a bounded, non-secret identity: provider-confirmed email plus an
  opaque provider account id. Access tokens, refresh tokens, organization metadata, provider instructions, and
  credential files never cross the profile API.
- Settings → Accounts shows one row per provider identity across trusted paired hubs. Device badges identify this
  device and each remote hub, whether the device is online, and whether that exact account is signed in there.
- Profile names remain device-local credential slots. Unidentified profiles are never merged merely because two
  machines happened to call a slot `claude-a` or `codex-a`.
- Remote-only identities are pre-populated in the local account list and offer **Log in here**. The app reuses a
  safe matching slot when one exists or creates a readable collision-free local slot; it never overwrites an
  unrelated local account.
- The OAuth handoff states which email is expected. Because provider browser sessions ultimately choose the signed
  in identity, AllMyAgents verifies the provider-returned email afterward. A mismatch is cataloged as the account
  that actually authenticated while the requested account remains visibly not logged in locally.

- Cargo check and warnings-as-errors Clippy pass for the desktop shell.
- Focused contracts cover provider identity redaction, profile-registry refresh/removal, fleet grouping, prevention

  payloads, and the native Tauri shell before tag publication.
