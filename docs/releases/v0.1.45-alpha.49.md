# AllMyAgents v0.1.45-alpha.49

## Image previews and downloadable agent outputs

Codex and Claude can now deliberately show images and share generated outputs in chat
using the same `publish_artifact` tool. Ask an agent to show its render, chart, or image:
the agent publishes the finished workspace file and an optional caption. PNG, JPEG,
GIF and WebP appear as inline thumbnails; click to expand or shrink, or download the
original. A failed image load shows an explicit retry control.

Generated STEP/STL files, ZIP packs, PDFs and other outputs appear as named download
chips. This is file sharing, not a 3D CAD viewer. SVG/HTML are downloads, never active
inline content. Existing file diffs remain in the action timeline.

Publications are immutable snapshots stored in the hub's `chat-artifacts` directory,
outside the project checkout, so changing or removing the source file does not change
an earlier preview. The same bytes/name/caption reuse the original publication rather
than adding duplicate messages. Live events and lazy history use the same attachment
identity; only small metadata enters the journal. Image bytes load lazily through the
existing authenticated attachment route. Back up `chat-artifacts` alongside hub.db;
a database-only backup does not contain attachment bytes.

## Boundaries

- The tool is bound to its calling chat and actual workspace, including WSL paths.
  It rejects URLs, outside-workspace paths, escaping symlinks and known private
  configuration paths. It grants no new device or filesystem authority.
- Previews are explicit: opening an image for internal analysis does not publish it.
  Local Markdown image syntax is not a substitute for the display tool. Remote URLs
  are not automatically fetched when a reply renders.
- Limits are 5 MiB per raster image, 32 MiB per other file, 256 files / 256 MiB per
  chat and 2 GiB of registered artifacts per hub. Reaching a limit refuses new
  publication with a clear error; it never silently deletes existing history.
- This does not add image generation to accounts without an image-generation tool,
  or automatically fetch artifacts from remote workers. Stage the finished output
  in the agent's workspace through its existing granted file tools first.

## Updating

The numeric application version is **0.1.45**, so 0.1.44 installations can detect it.
It also includes the worker durable-run permission, question attention/timers and
native-goal wait repair from 0.1.44. Use Settings → Check for updates after publication.
No OS reboot is required; this release does not restart your running app or services.
