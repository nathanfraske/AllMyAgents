# AllMyAgents v0.1.47-alpha.51

## Ubuntu remote execution without a source checkout

- Native `allmyagents-testbed` Debian packages for amd64 and arm64, with bundled Node and SHA-256 checksums. The remote machine needs MyOwnMesh but no AllMyStuff, AI login, npm, GUI, or project checkout.
- CLI installation with explicit access profiles: ordinary-user `full-machine`, root `elevated-machine`, dedicated passwordless-sudo `linux-sudo-machine`, or scoped roots. Package installation alone does not enable access or start services. Pair the exact peer and grant it to the intended chat/project.
- Machine-admin profiles start automatically at boot. Ordinary-user service starts at login; enable user lingering explicitly for boot startup and operation after logout. No OS reboot is required.
- `start_run` supports `remote_workspace: "machine"` for Kubernetes, host administration, non-Git directories, or deliberately dirty checkouts. It skips Git preparation and records machine-operation provenance; reproducible project builds keep the existing exact-commit checks by default.
- `timeout_ms: 0` explicitly disables execution deadlines. Current targets run independently of individual transport requests, retain admission receipts and terminal results, support cancellation, and never blindly repeat an ambiguous start. Older targets reject unsupported unlimited commands before execution instead of shortening their timeout.
- Temporary connection loss does not kill a command. An unobservable result remains `outcome_unknown`, not a false failure/success/cancellation. Source shutdown detaches polling and clears heartbeat timers without cancelling the remote command.

[Ubuntu installation and pairing guide](https://github.com/nathanfraske/AllMyAgents/blob/v0.1.47-alpha.51/docs/ubuntu-remote-node.md)

## Refreshable account model lists

- Refresh models in the account/model picker and account settings without starting an agent turn. Model discovery uses each account's own provider connection, including paired remote-account routing.
- Stale catalogs refresh in the background with bounded concurrency and retry backoff. Failed refreshes retain the last good catalog; removed selected models are not silently replaced.
- `New` badges expire after 90 days based on known release dates, not the day your installation first discovers the model. Unknown dates are not guessed.

## Compatibility and qualification

- Update the controlling AllMyAgents hub and remote node to use the new durable command protocol. `remote_exec` remains the short interactive tool; use `start_run` for long work.
- Remote output is bounded and retained at completion; this release does not add interactive PTYs, unlimited live output, or resumable execution across a source-hub/target restart. Drain active jobs before an intentional service upgrade/restart.
- Linux desktop/full-hub packaging and a qualified RISC-V package are not included. Automatic bootstrap onto a bare peer still requires the reviewed upstream MyOwnMesh transfer/bootstrap contract; no hidden SSH fallback is used.
- Local qualification includes 1,568 passing hub tests (one skipped), model-picker/web tests and type checks, installer rejection checks, and an extracted Ubuntu amd64 package executing a real 125-second unlimited command. Release jobs qualify native amd64 and arm64 packages independently. This is not a claim of live two-machine pairing or privileged-service qualification on your hosts.
- Desktop updater version increases to **0.1.47**. Windows installers are not Authenticode-signed. macOS builds remain ad-hoc signed and unnotarized; if Gatekeeper blocks the installed app, run `xattr -dr com.apple.quarantine /Applications/AllMyAgents.app`.

This remains an alpha. Machine-admin profiles grant real machine administration; ordinary-user mode does not bypass OS permissions or Kubernetes RBAC. Linux checksums are anchored to the official HTTPS release, not a separate package-signing key.
