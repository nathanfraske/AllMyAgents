# AllMyAgents v0.1.50-alpha.54

## GPT-6.1 Sol

- Adds account-discovered `gpt-6.1-sol` with low, medium, high, xhigh and max effort choices. The bundled Codex client is now **0.159.2**. Existing model selections and Daybreak preferences are not replaced.
- A valid empty or hidden-only account catalog remains empty across cached reads; unavailable models are not silently replaced with fallback choices. Refresh the account model list after updating. Provider entitlement is still required.

## File transfers and testbed updates

- Whole-file uploads and downloads use bounded 8 KiB application chunks instead of oversized transport messages. Files remain checksum-verified; uncertain writes are not automatically replayed.
- Remote response acknowledgements are checked, including explicit negative acknowledgements. A response failure does not rerun the underlying operation.
- Legacy testbed updates stage bounded, checksummed chunks and retain recovery information. This fixes the updater path used to upgrade older nodes that cannot yet serve whole-file transfers.
- The targeted repairs were exercised with a complete 9,101,212-byte download and a separate 351,163-byte upload. Those results do not claim that every route or upstream Mesh failure is repaired. Remote nodes still require their own authorized update.

## Operator controls and restart reliability

- Periodic roster refresh now brings persisted tool-help holds into the chat's review controls. Exact operator decisions refresh the current incident list, with a fence against stale responses restoring an already-resolved hold.
- A hub-only restart retains the supervisor's agent-tool credential, so surviving workers can reconnect to the replacement hub. Full application restart rotates it; authentication and operator-only controls remain enforced.
- Desktop notifications remember only bounded opaque delivery IDs locally. A failed acknowledgement followed by reload no longer repeats an already-shown notice, and read notifications are not shown again. The inbox remains available.
- Includes the task-first/stop lifecycle, existing-agent migration, configurable usage warnings, manager protection for direct operator work, Daybreak and local-fleet routing from [v0.1.49-alpha.53](https://github.com/nathanfraske/AllMyAgents/blob/v0.1.49-alpha.53/docs/releases/v0.1.49-alpha.53.md). Updates preserve existing operator settings, including disabled automatic tool escalation, and do not broaden permissions.

## Complete-platform publication

- Desktop installers, signed updater assets and Linux remote-node packages are staged in one exact-source draft. Publication requires every platform build and the existing launch/repair gates, plus a complete matching updater manifest.
- This replaces the publication path that exposed an incomplete v0.1.49-alpha.53 when Intel Mac packaging failed. The old tag is not moved. PR installer-script checks use the complete v0.1.48 baseline while separate gates build and install the current PR on both Mac architectures; explicit release checks remain bound to the requested tag.
- Windows, Intel Mac and Linux x64 builds keep the exclusive local-fleet routing. Apple Silicon, Linux ARM and the existing hosted installer/P0 checks retain their configured exceptions.

## Updating

Desktop updater version is **0.1.50**. Update the complete application bundle together. For the first upgrade from an older supervisor, fully quit and reopen the app once so the restart-authentication change is active in the supervisor as well as the hub. No OS reboot or Mesh upgrade is required by these patches.

Linux packages are remote-node packages for amd64 and arm64, not a Linux desktop application. Windows installers are not Authenticode-signed; macOS builds are ad-hoc signed and unnotarized. The existing macOS installer script and documented quarantine workaround remain applicable. This remains an alpha release.
